# For My Princess ♡

An intimate, mobile-first apology experience built with React + Vite.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to Vercel
Import this repository into Vercel. Framework preset: Vite; build command `npm run build`; output directory `dist`.

The response buttons are intentionally private to the visitor's browser. No response is transmitted or stored remotely.
