# For My Princess ♡

An intimate, mobile-first apology experience built with React + Vite.

## Run locally
```bash
npm install
npm run dev
```

## Build and verify
```bash
npm run build
npm run preview
```

A GitHub Actions workflow runs the production build on every push and pull request to `main`.

## Deploy to Vercel
Import this repository into Vercel. Framework preset: Vite; build command `npm run build`; output directory `dist`.

The response buttons are intentionally private to the visitor's browser. No response is transmitted or stored remotely. The experience does not pressure the visitor to forgive or respond; the 'I need a little time' choice is equally respected.
